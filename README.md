**Pokelytics** is an app that aims to improve upon the Pokedex by creating an AI-powered Pokemon Classification tool using Naive-Bayes , K-Nearest Neighbors, and K-Means Clustering, basing on the [Ultimate Pokemon Dataset (2026)](https://www.kaggle.com/datasets/darkmatternet/ultimate-pokmon-dataset-2025) from Kaggle. Through this tool, Pokemon trainers will have no trouble organizing their Pokedex and collected Pokemon because our state-of-the-art algorithms will be able to predict its type based on its predetermined features!
